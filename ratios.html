Exploring Ratios on the Guitar

Standard Tuning-

First you must tune the open strings so that they are in exact ratios with each other:

1) The lowest (6th) string is 1/1, the reference pitch.

2) Tune the 5th string harmonic at the seventh fret (12/3 or 4/1) to the 6th string harmonic at the fifth fret (4/1)

3) Tune the 4th string harmonic at the fifth fret (7/4) to the 6th string harmonic at the ~2+2/3 fret (7/4)

4) Skipping the 3rd string for now, tune the 2nd string open (3/2) to the 6th string harmonic at the seventh fret (3/2)

5) Tune the 1st string open (4/1) to the 6th string harmonic at the 5th fret (4/1).

6) Finally, tune the 3rd string harmonic at the fourth fret (3/2) to the 1st string harmonic at the seventh fret (3/2).
